# Build a Modern AI-Powered CCTV Video Intelligence Platform

You are a senior product designer, UX engineer, full-stack developer, AI/ML engineer, and security architect. Build a production-quality, modern **AI-powered CCTV Video Intelligence web application** that allows users to upload CCTV footage and automatically understand, search, analyze, summarize, and investigate the entire video using AI.

The product should feel like a premium combination of **video surveillance analytics + AI copilot + investigation workspace**, with a clean, modern, professional interface suitable for security teams, businesses, warehouses, retail stores, offices, campuses, factories, parking facilities, and other environments.

Do not build a simple demo or static dashboard. Build a highly polished, functional application architecture with realistic interactions, responsive UI, reusable components, clear states, and extensible AI/video-processing infrastructure.

---

## 1\. PRODUCT VISION

Create an application called:

**VisionGuard AI**

Tagline:

**“Turn hours of CCTV footage into actionable intelligence.”**

The core workflow should be:

1. User uploads CCTV footage.
2. System processes the complete video.
3. AI detects and tracks people and relevant objects.
4. AI identifies activities, events, anomalies, and unusual behavior.
5. AI generates a timestamped event timeline.
6. AI produces people/object counts and movement analytics.
7. User can search the video using natural language.
8. User can ask questions about the footage through an AI assistant.
9. Important moments are automatically extracted into clips.
10. The system can trigger alerts for configurable events.
11. AI generates an actionable investigation report.
12. User can review evidence, jump directly to timestamps, export clips, and download/share reports.

The application should prioritize **clarity, speed, investigation efficiency, and trustworthy AI explanations**.
